# 🏠 SmartLease

A full-stack enterprise Rental Management System built using **Java Spring Boot**. This project is designed to simplify property rental operations by providing secure authentication, property management, tenant management, lease tracking, rent collection, maintenance requests, and reporting.

---

## 🚧 Project Status

**In Development** 

---

## 🎯 Objective

Build a production-ready Rental Management System following industry best practices, clean architecture, and REST API standards.

---

# 🚀 Tech Stack
